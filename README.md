A program that writes one 1024x1024 newspaper image summing up the world's news of Wednesday 25 November 2026 — Shenzhou-24 carrying Pakistan's first astronaut to China's Tiangong station, two tankers hitting mines in the Strait of Hormuz, the Solomon Islands signing a security treaty with Australia, and a New York jury convicting Huawei — as a single broadsheet page, entry.png, with 40 dated stories, a markets strip, and a world map keyed to the stories.

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
